2025.03 – 현재 제1저자 · 연구 주도 LLM · Generative Recommendation

LLM 기반 사용자 방문기록 분석 및 다음 방문지(POI) 추천 시스템 연구

석사 과정에서 사용자의 방문기록(Trajectory) 데이터로 다음 방문지를 예측하는 LLM 기반 Generative Recommendation을 연구하고 있습니다. 기존 Semantic ID 기반 추천은 POI의 제한적인 텍스트 정보만으로 실제 이동·방문 패턴을 충분히 표현하기 어렵습니다. 이 문제를 풀기 위해 LLM의 텍스트 정보와 User-POI Graph의 사용자 행동 정보를 함께 활용하는 추천 모델을 설계했습니다.

PIVOT: Dual-View POI Semantic IDs with Vocabulary-Only Tuning for Generative Next-POI Recommendation — 제1저자, WSDM 2027 투고(심사 중). 관련 결과를 한국정보과학회 2026에 제1저자 논문으로 게재. 본 연구로 한국연구재단 「석사과정생 연구장려금」 지원 대상 선정.

수행 내용

  • Dual-View Semantic ID 구조 개발 — LLM 기반 Text Embedding과 User-POI Graph에서 LightGCN으로 학습한 Collaborative Filtering Embedding을 각각 RQ-VAE로 양자화하여, POI의 의미 정보와 실제 방문 패턴을 함께 표현.
  • Vocabulary-Only Tuning — 새로 만든 Semantic ID Token을 LLM에 학습시킬 때 LoRA 대신 Backbone을 고정하고 SID Embedding과 Output Parameter만 학습하는 방식을 설계. 방문기록 전체 SID에 학습 신호를 주는 Trajectory-wide SID Loss를 함께 개발.
  • 모델 평가 — NYC, TKY, CA 실제 사용자 방문 데이터셋에서 Graph 기반, Sequential Recommendation, LLM 기반 Next-POI 추천 모델과 성능 비교·분석.

결과

  • 3개 데이터셋 모두에서 기존 SOTA 모델을 상회하는 추천 성능 달성.
  • Vocabulary-Only Tuning으로 LoRA 대비 학습 Parameter 약 1/4 수준으로 절감, 생성 속도 약 2.2배 향상.

임베디드/Edge 환경 경량 딥러닝 모델 개발 — IMU 센서 기반 행동 인식

학부 4학년 기간, 자이로/가속도(IMU) 센서 데이터로 인간 행동을 분류하는 문제를 다뤘습니다. 컴퓨터 자원이 제한적인 IoT 환경에 맞는 딥러닝 모델을 만들기 위해 모델 구조 개선과 경량화를 주제로 연구했습니다.

Improved Deep Learning Structure with Lightweight Depth-wise Convolutions for Human Activity Recognition — 제1저자, Human-centric Computing and Information Sciences (SCIE Q1) 게재. 2023 한국소프트웨어종합학술대회 학부생/주니어 논문경진대회 우수상.

수행 내용

  • 모델 경량화 — 기존 SOTA인 ResNet-SE 모델에 Depth-wise Convolution을 적용해 구조를 경량화.
  • 센서 데이터 수집 및 처리 — Public 데이터 외에 실제 사용자를 대상으로 실험을 진행하여 IMU 센서 데이터를 직접 수집·처리.
  • 온디바이스 평가 — 이전 논문 모델들과 Public 데이터에서 정확도를 비교하고, TF-Lite로 Android와 Raspberry Pi(Linux)에 배포하여 실제 기기에서 성능 비교.

결과

  • Convolution을 Depth-wise Convolution으로 대체해 Parameter와 FLOPs를 줄이고 overfitting을 완화하여 정확도 향상.
  • Inference time, CPU 사용량, 에너지 소비 모두에서 기존 모델보다 효율적인 모델 개발.
